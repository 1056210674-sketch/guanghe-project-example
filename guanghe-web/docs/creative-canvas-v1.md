# 创作画布首版交接

2026-10-27。入口：左侧“创作画布”，列表 `/app/canvases`，详情 `/app/canvases/:canvasId`。

## 用户流程

1. 新建画布，可关联客户项目，也可直接个人创作。
2. 拖入、粘贴或上传 PNG/JPEG，或从同一项目的资产中心放入已有图片、视频。也可添加文字和方案便笺。
3. 选中图片，将用途改成商品、人物、背景、风格或 Logo。连到方案的素材也会明确列入引用。
4. 填写一句要求；可以优化描述、编辑结果和恢复原话。默认在预览制作前优化。
5. 选择图片或视频、比例、数量/时长。多款商品可分别搭配公共人物/背景，按每行一个场景展开变体。
6. 预览展开项和真实总积分，一次确认后后台制作。可继续编辑、离开、刷新；制作记录关联原有正式任务。
7. 结果出现在画布，也可切到“作品”选稿。同类素材可以“收为版本”、切换版本并展开对比。单文件走既有原文件下载；多选打包 ZIP（每次最多 20 个、原文件合计 64 MiB）。

选中一张图片可连接既有蒙版重绘，或把它作为首帧制作视频。工具按 Java 配置显示。视频生成沿用已有模型与价格，首版交付单个片段。

## 数据与恢复

- Java 是真相源：V063 追加 `creative_canvas`、`creative_canvas_batch`、`creative_canvas_prompt_attempt`，没有改写旧迁移。
- 节点只保存资产 ID，临时链接通过既有资产接口读取。结果和任务从批次投影，不跟布局覆盖。
- 保存使用版本校验与串行写入。素材选择、关联连线、生成参数和蒙版随文档恢复。未保存编辑按用户和画布隔离缓存；冲突时保留本地草稿，可下载后重新加载。
- 撤销、删除节点、删除画布、复制节点/画布都不发起生成，不撤销已确认任务，不删除正式文件。
- 批次固定原话、优化描述、来源顺序、角色、参数与报价。重试必须用户再次预览确认；未决结果不开放重下单。
- 提示词优化复用对话分钟/每日文字额度，不新增图片或视频扣费。已优化图片关闭供应商二次扩写；旧流程维持原默认值。
- Web 仅调用 Java `/api/v1/creative/canvases`；Java 使用既有 HMAC 客户端调用 Python 的 `canvas-prompts`。执行仍走原 Task/Outbox/Worker/积分。

## 开源

交互内核使用固定版本 `@xyflow/react@12.12.0`（MIT），包括拖动、缩放、框选、连线、控件和小地图。保留包内许可及默认署名。没有搬入其他项目的账户、钱包、浏览器供应商密钥或本地任务后台。

## 验收范围

自动验证限于当前实际流程：前端四条交互（延迟优化、一次报价/确认、异步保存/刷新、配对/删组），Java 归属/版本/契约与原素材规则，隔离 PostgreSQL V062→V063、真实任务与积分事务、重复确认、复制和软删除。模型适配使用离线响应，没有真实模型调用或生成费用。

实际验证：`npm run build`；`npm run test -- --run src/test/canvas-interactions.integration.test.tsx`。画布交互四项通过；`npm run test -- --run src/test/platform-navigation.integration.test.tsx` 三项通过，检查新入口、账户菜单和旧书签，导航不创建业务任务。Java 与隔离数据库结果见对应仓库交接记录；Python 画布/图片适配 57 项通过。未把这些结果表述为全项目测试全绿。

本版批量提供“同一画面”和“每件商品分别搭配公共参考”、场景变体。尚未增加多模特全组合、逐行手工配对、`@` 素材选择器或独立裁剪工具；当前用选择节点和连线明确引用。前端展开制作明细，Java 逐项验证来源、数量和真实总价后原子受理。

页面拖动、缩放、真实素材生成的外观及视频效果由用户验收。尚未加入专业图层排版、CSV 数据套版、轻量时间线或合成 MP4；这些按产品文档进入后续阶段。也未把本次角色描述优化当成图片视觉识别。
